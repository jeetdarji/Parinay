# PyTorch CPU-only wheel index. MUST stay at the top so pip resolves the
# +cpu build of torch instead of the default CUDA-bundled wheel. The CUDA
# wheel is ~750MB+ unpacked and will OOM / exceed disk on Render's free tier.
--extra-index-url https://download.pytorch.org/whl/cpu

fastapi==0.110.3
uvicorn[standard]==0.29.0

# NOTE: torch is pinned to 2.4.1+cpu (CPU-only). Without the +cpu pin and the
# --extra-index-url above, pip on Linux (Render) installs the CUDA build and
# the service runs out of memory/disk on the 512MB free tier.
#
# NOTE: fastapi is pinned to 0.110.3 (not 0.111.0). fastapi 0.111 pulls in
# fastapi-cli -> typer>=0.12, which conflicts with spacy 3.7.4 -> typer<0.10.
# 0.110.3 has no fastapi-cli dependency and is functionally identical for our
# use (we run via `uvicorn main:app`, not the `fastapi` CLI).
#
# NOTE: pydantic is pinned to 2.8.2 (not 2.7.1). On Python 3.12.7, pydantic
# 2.7.x's bundled v1 shim crashes spaCy import with
# "ForwardRef._evaluate() missing 1 required keyword-only argument". 2.8.0+
# fixes this. Pydantic v2 model syntax is unchanged.
#
# ---------------------------------------------------------------------------
# RENDER DEPLOYMENT
# ---------------------------------------------------------------------------
# PYTHON VERSION:
#   Render ignores runtime.txt. Python is pinned via .python-version (3.11.9)
#   or the PYTHON_VERSION env var in the Render dashboard (takes precedence).
#   Without this, Render defaults to Python 3.14 which has no pre-built wheels
#   for blis/thinc/spacy and the build will fail.
#
# Build Command:
#   pip install -r requirements.txt && pip install \
#     https://github.com/explosion/spacy-models/releases/download/en_core_web_sm-3.7.1/en_core_web_sm-3.7.1-py3-none-any.whl
#
# Start Command:
#   uvicorn main:app --host 0.0.0.0 --port $PORT
#
# (The en_core_web_sm wheel is installed directly because `python -m spacy
#  download` can fail behind the compatibility-table lookup. The --extra-index
#  -url line in this file makes `pip install -r requirements.txt` fetch CPU torch.)
